==================================================
1. CORE PRODUCT IDEA
==================================================

KaamSetu is a platform that connects customers with local skilled workers.

The platform will allow customers to post a job request for work such as:

- Electrician
- Carpenter
- Plumber
- Painter
- General Labour
- AC Technician
- Appliance Repair
- RO Technician
- Mason
- Cleaning
- Furniture Assembly
- Gardening
- Other local services

The most important feature of KaamSetu is:

CUSTOMER DOES NOT SIMPLY BOOK A RANDOM WORKER.

Instead:

CUSTOMER CREATES A JOB REQUEST
        ↓
CUSTOMER UPLOADS PHOTOS
        ↓
CUSTOMER DESCRIBES THE WORK
        ↓
CUSTOMER SELECTS DATE + TIME
        ↓
SUITABLE NEARBY WORKERS RECEIVE THE REQUEST
        ↓
WORKERS REVIEW PHOTOS + DESCRIPTION
        ↓
WORKER ACCEPTS OR REJECTS
        ↓
BOOKING IS CONFIRMED
        ↓
WORKER STARTS JOURNEY
        ↓
CUSTOMER CAN TRACK WORKER
        ↓
WORKER ARRIVES
        ↓
WORK STARTS
        ↓
WORK COMPLETED
        ↓
CUSTOMER RATES WORKER


This worker-first job evaluation system is the core differentiating feature of the platform.

13. WORKER LOCATION TRACKING
==================================================

Implement location tracking carefully.

DO NOT continuously track workers.

Location sharing should only activate for an accepted/active job.

Worker clicks:

"START JOURNEY"

Then location sharing begins.

Customer sees:

Worker name
Worker profile photo
Current/last known location
Approximate distance
Last updated time
Journey status

Example:

"Rajesh is 1.4 km away"

"Location updated 18 seconds ago"

Worker can stop location sharing when:

- Worker arrives
- Job is cancelled
- Job ends

Use browser/device Geolocation APIs.

Use WebSockets or Supabase Realtime for real-time updates.

If real GPS cannot be tested without external API configuration, create a mock location mode for development.

NEVER expose private API keys.
